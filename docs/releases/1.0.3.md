# 星露谷手册 1.0.3

日期：2026-10-09（Asia/Shanghai）。

修复部分 Windows 便携运行目录转换为 8.3 短路径后，页面显示「请求来源无效」而无法初始化的问题。程序现在固定校验自己实际加载的页面 URL，同时验证调用来自这个窗口的当前主框架；其他窗口、子框架和后续不同页面不能调用程序 IPC。

问题在 GitHub 的 Windows 运行环境中发现：文件页面路径使用 `RUNNER~1`，与 Node 侧构造的长路径不同。新增回归测试覆盖短路径、不同窗口、不同进程与框架、空框架，以及后续页面不能替换可信页面的情况。

本机验证：12 项单元测试通过；1.0.3 安装包完成安装、启动、卸载和重装，原生读取桌面与开始菜单快捷方式目标正确，测试收藏保留，用户现有资料文件哈希不变；1.0.3 便携版通过实际解压、启动、初始化和离线词条阅读。

公开仓库：[shguild/stardew-handbook](https://github.com/shguild/stardew-handbook)。Windows/Linux 自动测试及标签触发的 Windows 安装包发布流程已配置，流程包含实际安装、重装、25 个旧词条缓存样本的 50 个读取场景及便携版验收。

旧版 1.0.2 保留，新版安装包名为 `Stardew-Handbook-1.0.3-Setup-Windows-x64.exe`。安装方式、收藏目录和 Wiki 来源不变。下载新版或后续版本见 [Releases](https://github.com/shguild/stardew-handbook/releases)。
