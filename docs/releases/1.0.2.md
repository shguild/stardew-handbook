# 星露谷手册 1.0.2 安装版

日期：2026-10-09（Asia/Shanghai）。

新增 Windows x64 中文 NSIS 安装包。只需分发一个 Setup EXE，接收者即可安装完整程序，无需 Node.js、Python 或游戏文件。沿用 1.0.1 的全部词条正文修复、官方 Wiki 来源和内置资料。

## 安装行为

- 中文安装向导，允许选择安装目录。
- 固定为当前用户安装，默认使用当前用户的程序目录，不请求管理员提权。
- 自动创建「星露谷手册」桌面和开始菜单快捷方式。
- 提供 Windows 已安装应用列表中的卸载入口和安装目录中的卸载程序。
- 安装完成页可直接启动程序；卸载默认保留收藏、历史、设置和缓存。
- 程序 EXE 内嵌自绘图标、软件名称及 1.0.2 版本信息。
- Windows 10/11 x64；首次查询未缓存的官方词条需要联网。
